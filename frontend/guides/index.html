Guía operativa de Anomalía

Esta colección describe el comportamiento real del gateway Nginx + FastAPI, el ejecutor de jobs sobre PostgreSQL y el stack de observabilidad desplegado con Ansible. Cada guía es autocontenida y se puede abrir de forma directa.

Regla de oro: el inventario define la topología y la base define la autorización. Ningún widget, token o archivo local amplía privilegios por sí solo.

Ruta de lectura recomendada

1. Inicio rápido

Alta, acceso y primera consola en minutos.
2. Arquitectura

Componentes, flujos y ejecutor único de jobs.
3. IAM y ABM

Usuarios, roles, perfiles y solicitudes.
4. Alta de tenants

Job background, fases y rollback.
